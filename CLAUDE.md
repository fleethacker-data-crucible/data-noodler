# Data Noodler

- Keep all responses brief.
- `.ps1` files must be ASCII only (no `…`, `—`, `✓`): Windows PowerShell 5.1 reads them as ANSI and garbles anything else.
- Read `ARCHITECTURE.md` (how the server, file API and native C# engine work) before server/engine work; `CODE_INDEX.md` is the file map.
- `.trash/` holds retired files. Never read, search, reference, restore or reuse anything in it unless explicitly told to.
