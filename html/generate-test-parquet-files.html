Test Parquet generator

Builds datasets of synthetic sales data with 50 columns into test-data/gen/<name>/: Parquet part files (ZSTD, 100k-row row groups) plus a manifest.json. Every value is computed from the row id, so the data is the same every time and an interrupted run picks up where it stopped. Parts are generated in parallel by several DuckDB engines.
