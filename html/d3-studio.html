D3 code live file

The chart is drawn in its own <div> (el), W x H px. Return an svg (svg.node()) or draw into el: the chart's root svg always scales to fit its box (a fixed width / height from pasted code gets a viewBox), here and on the Dashboard.
Inputs (right) are the chart's data variables: each one is a column of data (d.x, d.y) with an accessor in capitals (X(d), Y(d)), listed in the Generated box above the code. Pick the Data table (top right, a cleaned CLEAN_ dataset) and a field of it for each input to draw real data; until then the Sample data is drawn. On the Dashboard a new chart starts empty (axes and grid only) until its fields are linked in Right-click > Chart Settings.
Also ready: colors (the 8 colours), opts (Settings: opts.grid.x ...), theme (text, text2, muted, border, font), inputs.x.label / .field (axis titles), width / height (= W / H).
Editor: suggestions as you type (d3. lists all of D3 v7, svg. / x. the methods of that selection / scale, d. the inputs), Ctrl+Space lists everything, hover a D3 name for what it does, Ctrl+/ comment, Ctrl+F find, Ctrl+Enter run. Errors: dark orange on the line you are typing, dark red elsewhere, green flash when fixed; hover one for the message.
